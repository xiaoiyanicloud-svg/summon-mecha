# 内容安全 · 本地词表（种子）
#
# ⚠ 这是**种子表，不是合规词表**。上线前必须由合规方/内容安全服务补全，
#   或直接切到微信 msgSecCheck（见 config/content_safety.php 的 wechat 留位）。
#
# 格式：
#   普通行       → 子串匹配（大小写不敏感，且会先在"去空白/分隔符"的规整文本上再扫一遍）
#   re:正则      → 按正则匹配。**裸模式即可**（`re:赌.{0,3}博`）——
#                  扫描器会自动包定界符并补 `u`；也可以自己写成 `/…/u` 的完整形式。
#   # 开头       → 注释
#
# 选词原则：只收**明确违法**、且**不可能出现在合法机器人技能文案里**的词，
# 宁可少收也不要误伤 —— 误杀会逼开发者反复重提，比漏检更容易让人放弃平台。
