## ① A5 · 关闭"安装失败回退" → A5-10 / A5-11 两红

变异（`agent/zhjj_agent/task_manager.py` 的 `_abort_install`）：

```python
try:
    return  # MUTATION: 关闭安装失败回退
    with transaction.lock(skill_id):
        transaction.abort_commit(committed_dir, backup_dir)
```

命令：

```
python -m unittest tests.test_install_transaction.TestTaskManagerInstallRollback.test_a5_10_... test_a5_11_...
```

红（节选）：

```
AssertionError: True is not false     # A5-10：首装失败后版本目录仍存在
AssertionError: True is not false     # A5-11：健康探针失败后版本目录仍存在
Ran 2 tests ... FAILED (failures=2)
```

还原后：

```
Ran 2 tests in 1.691s
OK
```

结论：A5-10/A5-11 断言的是"失败路径真的把半成品清掉了"，不是"函数返回 False"。

## ② A6 · 只杀父进程、不杀进程树 → A6-07 红

```python

try:
    process.kill()
except OSError:
    pass

```

命令：

```
python -m unittest tests.test_sandbox.TestSubprocessSandbox.test_a6_07_...
```

红：


```
Ran 1 test in 4.650s
OK
```

结论：A6-07 真的在验证"孙进程也被杀掉"（Windows 走 `taskkill /T`，POSIX 走 `killpg`），
不是只看父进程返回值。
