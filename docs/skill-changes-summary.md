# 技能平台 · 近期改动汇总（白话 + 表格版）

> **一句话总览**：2026-10-15 这一天，我们把技能平台**从「能跑的架子」补成了「上线不出事」** —— 修完了一批会**漏钱 / 发错货 / 被越权**的洞，补齐了平台后台、开发者门户后段、合规与运维底座，并把长期没提交的 3061 项改动**一次性归了库**。
>
> **时间范围**：2026-10-15（本项目当前全部 58 个提交都集中在这一天）。
> **提交总数**：**58 个**（其中 3 个是「把积压工作一次性入库」的重基线提交，其余 55 个是功能加固、收口与文档）。
> **这份文档回答一个问题**：**这两天到底改了什么，让不懂代码的人也能看懂。**

> ⚠ **读之前先记住三条红线（写错就是方向事故）**：
> 1. 我们卖的是**买断制**，不是订阅（定价字段是 `pricing_mode='buyout'`）。
> 2. 设备的**唯一真相源是 `device_binding`**（`devices` 表只是登记视图），下发逻辑只认 binding。
> 3. 兼容性分**三级**：L1 可交付 / L2 可适配（只承诺"可转换"）/ L3 仅展示不发售 —— **不承诺跨品牌开箱即用**。
>

## 12 · 与《技能供需开发计划》v3.4 §4 模块的对应

> **为什么要这张表**：本文（改动白话汇总）回答「**这几天动了什么**」，主计划 [skill-supply-plan.md](./skill-supply-plan.md) 回答「**整个平台要做成什么样**」（模块定义在 §4.1–§4.22）。两张表对不上，就会出现「改了一堆东西，但说不清补的是哪块版图」。
>
> **读法**：左边是主计划的模块编号，右边是**本轮到底兑现了什么（白话）**。写「**本轮未动**」= 这几天**没有**对应提交，**不代表这块从未实现**（有些代码在「重基线入库」那 3 个提交里就带进来了，只是本轮没再加固）。

> **现状口径**与主计划一致：✅ 完成 ｜ 🔶 部分 ｜ ❌ 未做 ｜ ⏸缓做。其中 §4.2 支付资质未就绪、§4.9 结算提现、§4.15 开发者门户（0 个第三方开发者 → 缓做）三项**与主计划判断一致**。
