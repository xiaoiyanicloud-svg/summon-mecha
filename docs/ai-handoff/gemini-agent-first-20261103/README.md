# Gemini Agent与转码器完整交接包

这两份文件是可直接上传给Gemini编程代理的完整任务书。两份都嵌入：两份计划全文、独立验收报告全文、AGENTS、CLAUDE、HANDOFF、项目brief，以及标准源样例和原始校验范围。无需再从聊天记录拼资料。

## 使用顺序

1. 先把 `01-gemini-agent-full-prompt.md` 交给能访问真实仓库和终端的Gemini，要求执行正文任务，不只总结附件。不要同时给两个AI改同一工作区。
2. 第一阶段按A-T01—26交付代码、原始输出和HTTP集成证据。不能凭“已完成”文字放行；复跑门槛有失败就继续返工。
3. 第一阶段软件门槛通过后，再交 `02-gemini-transcoder-full-prompt.md`。它包含前置门槛全文及C-T01—24，仍区分软件、SDK和真机验证。
4. `independent-acceptance-evidence.zip` 是此前独立验收的原始脚本、输出和校验值；历史基线是44ca8ff，复现前检查新修复。

正文已授权普通代码修复；外部硬件、生产动作和业务红线不允许AI自行假定批准。仓库迎宾样例缺音频，不能直接当完整成品；任务书要求把它作为缺素材负例，并准备有权使用的完整测试源。
