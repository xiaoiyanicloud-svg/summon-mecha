# ADR-0002：冻结通用运动编译器与跨机型轨迹转码

- 日期：2026-11-06
- 状态：Accepted
- 决策人：项目负责人
- 关联：ADR-0001、`docs/skill-supply-demand-audit-and-blueprint.md`

## 背景

项目当前仍以真实机器人场景服务、技能供需和可信交付为业务主线。现有技能平台已经具备包校验、签名、目标绑定、审核发布、设备授权、交付和审计等基础能力。

此前进一步推进了通用运动编译、跨机型动作重定向、物理动力学验证和五机型 HIL。这些能力具有长期技术价值，但在当前阶段缺少足够真实订单、真机、厂商限值和运营数据支撑，继续投入会挤压真实需求验证和技能市场冷启动。

## 决策

自 2026-11-06 起冻结以下方向：

- 通用运动编译器
- 跨品牌动作重定向
- 关节空间轨迹生成
- BVH/SMPL-X/CSV 等任意动作源转目标机型
- 动力学、碰撞、力矩、温升等物理验证扩写
- 五机型同步 SIL/HIL
- A3/T800 的深度机型适配
- 编码器与主平台的新集成
- 为未来行业标准提前增加的通用抽象

冻结不等于删除。相关代码保留为 `EXPERIMENTAL` 或默认关闭的技术储备，不再作为当前发布门禁、MVP 完成度分母或新增研发主线。

## 保留范围

继续维护和迭代以下能力：

- Manifest、技能包结构和安全校验
- 文件哈希、签名、限时下载和授权
- 目标机型绑定与基础 Profile
- 技能审核、发布和 L1/L2/L3 支持矩阵
- 下载、人工安装、Agent 安装、回滚和熔断
- 手动交付通道
- 厂商原生静态动作或预录动作回放
- 设备绑定、订单、授权、执行事实、审计和售后
- 单个已验证机型的静态回播闭环

## 解冻条件

只有同时满足以下条件，才重新评估冻结范围：

1. 至少 3 个真实付费客户提出同一类跨机型技能需求；
2. 已取得目标厂商官方 SDK、经确认的物理限值和测试设备；
3. 已形成稳定的编码器输入/输出契约和确定性金标准测试；
4. 业务负责人确认该能力能带来明确的商业价值，而非仅技术演示；
5. 具备安全责任、HIL 场地和独立证据链。

## 影响

- 当前产品完成度按真实技能市场、技能交付和客户复购衡量，不再按五机型通用动作编译能力衡量。
- 冻结模块保持可回滚，不删除、不对外宣传、不新增功能。
- 编码器如需单独研发，应采用独立仓库/CLI 形态，不阻塞主平台。
- 任何解冻必须新增 ADR 或在本文补充修订记录。
