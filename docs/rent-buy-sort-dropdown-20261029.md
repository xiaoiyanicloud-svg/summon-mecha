# 租用 / 购买综合排序下拉（2026-10-29）

## 改动

- 租用与购买共用同一个「综合排序」下拉，替代原有「综合 / 价格↑ / 价格↓」平铺入口。
- 下拉选项：综合排序、好评优先、销量优先、最低价格、最高价格。

- 价格排序：沿用现有商品目录实际售价。
