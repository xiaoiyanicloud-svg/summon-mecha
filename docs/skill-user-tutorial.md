# 技能平台 · 用户手册（零基础版 · 从拆箱到下发成功）

> 目标读者：**没接触过命令行的普通用户**。
> 本文假设你**从没见过"终端"**、不知道 SSH 是什么。每一步都写清"在**哪台设备**上、**点/敲**什么、**会看到**什么。
> 三家机器人（宇树/智元/众擎）**第 0–2 步完全相同**，只在**第 3 步"装 Agent"** 时不一样。

---

## 📖 第 0 步：先搞懂 3 个词（30 秒）

1. **终端**：一个"敲命令的黑框框"。电脑自带的，不用装。
   - **Windows**：按键盘 `Win 键 + R` → 输入 `cmd` → 回车 → 出现黑框，就是终端。
   - **Mac**：按 `Command + 空格` → 输入 `终端` 或 `Terminal` → 回车 → 出现白/黑框。
2. **SSH**：一种"用命令远程登录另一台电脑（这里是机器人）"的方式。**就是敲一行命令**，不用懂原理。
3. **IP 地址**：机器人在网络里的"门牌号"，比如 `192.168.123.164`。**每家的门牌号不同，手册里会给你**。

**你只要会：复制手册里的一行命令 → 粘贴进终端 → 回车。** 就这么多。

## 🌐 第 1 步：让机器人先联网（**必须先做**）

> 为什么：Agent 要"主动连到平台"，机器人不上网就装不了。
> 怎么做：让机器人连上你家/公司的 WiFi。

**方法一（推荐，用手机 App）**
- 用**宇树/智元/众擎各自的手机 App**，按 App 引导给机器人配网（连 WiFi）。
- 配好后，App 里能看到机器人"已联网"。

**方法二（用电脑命令，稍后在第 2 步进终端后操作）**
- 先完成第 2 步连上机器人，再敲：
  ```
  sudo nmcli device wifi connect "你的WiFi名" password "你的WiFi密码"
  ```
- 看到 `successfully activated` 就是连上了。

> ✅ 判据：机器人能联网（App 显示在线 / 或稍后测试）。

## 🔌 第 2 步：用电脑连上机器人

### 2.1 插网线
- 网线一头插**电脑**，另一头插**机器人**的网口（宇树 G1：机身侧面网口；智元：有线调试口；众擎：背后网口）。
- 机器人**保持开机**。

### 2.2 给电脑设一个"同网段 IP"（**小白最容易卡的一步**）

> 为什么要设：机器人内网是固定网段（如 `192.168.123.x`），你电脑也要在同一个网段才能连上。

**Windows 设置方法：**
1. 右下角网络图标 → 右键 → **打开网络和 Internet 设置**
2. → **以太网** → **编辑 IP 分配** → 选 **手动**
3. 打开 **IPv4**，填：
   - IP 地址：`192.168.123.100`（各家网段见下表）
   - 子网掩码：`255.255.255.0`
   - 网关：留空
4. 保存。

**Mac 设置方法：**
- 系统设置 → 网络 → 选 **以太网** → **详细信息** → **TCP/IP** → 配置 IPv4 选**手动** → 填同样的 IP/掩码。

**各家的网段（照抄）**：
| 机器人 | 电脑设的 IP | 机器人地址 |
|---|---|---|
| 宇树 G1/Go2 | `192.168.123.100` | `192.168.123.164` |
| 智元 A2 | `192.168.2.100` | `192.168.2.50` |
| 众擎 PM01 | `192.168.0.100` | `192.168.0.162` |

### 2.3 打开终端，敲登录命令
按第 0 步打开终端，**复制对应这行**，粘贴，回车：

| 机器人 | 登录命令 | 首次密码 |
|---|---|---|
| **宇树 G1** | `ssh unitree@192.168.123.164` | `123` |
| **智元 A2** | `ssh agi@192.168.2.50` | 见机器人随机密码卡 |
| **众擎 PM01** | `ssh ubuntu@192.168.0.162` | `ubuntu` |

**第一次连接会问 `Are you sure...(yes/no)?` → 输入 `yes` 回车 → 再输密码**（输密码时**屏幕不显示**，正常，敲完回车即可）。

> 看到提示符变成 `unitree@ubuntu:~$`（或类似）→ **成功进入机器人了！**

## 🤖 第 3 步：装 Agent（各家不同）

### ▶ 场景 A：宇树 G1 EDU

**A-1 先改密码（安全，必做）**
```
passwd
```
按提示输入新密码两次。（默认 `123` 太弱，务必改。）

**A-2 让机器人联网**（若第 1 步方法二没做）
```
sudo nmcli device wifi connect "你的WiFi名" password "你的WiFi密码"
```

**A-3 安装 Agent**（复制平台给你的这行，`--token` 后面的码在你手机"我的设备→绑定引导"里）
```
curl -fsSL https://<平台域名>/agent/install.sh | bash --token ZHAOHUAN-8F3K
```
你会看到滚动几行文字，最后出现：
```
✅ Agent 安装完成，设备已注册：DID-ZH-1a2b3c
```
> 若提示 `sudo` 要密码，就再输一次你刚才设的密码。

**B-1** 用上面命令登录后（`agi@...`，账号自带 sudo 权限）：

**B-2 安装**（脚本会**自动按智元约束**装在 Orin 侧、不用宿主机 apt、走容器）：
```
curl -fsSL https://<平台域名>/agent/install.sh | bash --token ZHAOHUAN-8F3K
```
看到 `✅ Agent 安装完成，设备已注册` 即可。

### ▶ 场景 C：众擎 PM01

**C-1** 登录 `ubuntu@192.168.0.162`（密码 `ubuntu`）

**C-2 先改弱口令**：
```

```

## 🧰 第 6 步：出问题怎么办（排错表）

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 终端敲 `ssh` 报"无法连接/超时" | 电脑 IP 没设对 / 网线没插好 | 回第 2 步，检查 IP 网段和网线 |
| 提示 `Permission denied` | 密码打错 | 重敲；密码输入时不显示是正常的 |
| 安装脚本卡在"连接平台" | 机器人没联网 | 回第 1 步让机器人连 WiFi；`ping baidu.com` 测通不通 |
| 手机看设备一直"未绑定" | Agent 没注册成功/网络不通 | 终端里再跑一次安装命令，看报错 |
| 找不到"绑定引导"里的 token | 没在平台点"添加设备" | 先在"我的设备→添加"生成 token，再装 |
| 机器人是基础版，`ssh` 直接被拒 | 该机型不开放 | 只能走**纯手动**，或换开放版 |

## 💡 给产品团队的建议（本手册暴露的体验问题）

**小白卡点集中在"终端 + 静态 IP + SSH"三处**——这不是用户该承受的门槛。建议平台**额外提供**：
1. **一键配对小工具**（Windows/Mac 桌面程序）：用户插网线 → 打开工具 → 点"连接并安装" → 工具自动设 IP、SSH、装 Agent，**全程图形化，不碰终端**。
2. **视频教程**（每厂家一段，90 秒）。
3. **远程代装**（付费服务）：远程协助，适合完全不懂的用户。
4. Agent 安装脚本**带自检**：跑完自动测网络、测注册，直接告诉用户"哪一步失败、怎么修"。

> **一句话**：技术上装 Agent 只需一条命令，但**让小白走完"设 IP→SSH→联网"这条路才是真门槛**。平台的价值就是**把这个门槛尽量磨平**（工具/视频/代装三件套）。
