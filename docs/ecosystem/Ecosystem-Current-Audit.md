## 3 可复用的工程基础

保留uni-app与Laravel/Bagisto模块化单体，扩展现有赛事ID和公开入口。复用管理账号、现有客户令牌、StateView、站内通知、队列调度、必要审计、富文本和图片处理依赖；新增领域的去重、范围和发布约束仍需实现。

CMS静态协议页、营销活动、Booking商品票种各有既有语义，不与机器人赛事/新闻强行合并。开发者技能提审、授权和设备交付继续走既有边界；作品获奖不等于安全审核或真机部署通过。

## 5 首批修复顺序

先消除正式页面假数据与假成功、默认关闭旧站内报名写入口，再补后台逐动作授权、资料与导出隔离、编辑回填。随后建设可信发布和独立详情，最后在身份、版本、名额与通知协议全部验收后逐活动开放免费报名。完整赛事继续做到组队、作品、赛程、成绩、申诉及奖项；每一阶段都有独立签收，不将首页卡片或联系人落库记为平台完成。
