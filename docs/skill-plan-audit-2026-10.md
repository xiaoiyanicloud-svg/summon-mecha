# 机器人技能供需平台 · 开发计划深度体检报告（对照 v3.1）

> 日期：2026-10-10 ｜ 体检对象：[skill-supply-plan.md](./skill-supply-plan.md) v3.1
> 体检口径：**技能供需功能要达到"国内机器人服务头部平台"水平，用户端 / 开发者端 / 平台端全覆盖**
> 对标基准：宇树 UniStore、智元 AIMA（open.agibot.com / Genie Studio）、Apple App Store + App Store Connect、微信小程序后台、电商中台
> 依据可信度：宇树/智元/Apple/微信为**官方一手**；UniStore 细则、达闼为**媒体转述**（标 ⚠）

---

## 0. 一句话结论

**v3.1 把"交易的管道"和"物理安全的责任"写扎实了，但它是一条腿——开发者端几乎空白、合规是零、平台端缺风控与事故闭环。按"头部水平、三端全覆盖"标准衡量：用户端约 60%、平台端约 55%、开发者端约 20%、合规安全约 10%。**

| 端 | 成熟度 | 判断 |
|---|---|---|
| 用户端（C 端买家） | **~60%** | 交易/设备/技能使用主链路在，但**售后、客服、通知、搜索、评价接入**成体系缺失 |
| 开发者端 | **~20%** | **最大结构性缺口**：没有独立开发者门户，开发者"没有自己的登录面" |
| 平台端（运营后台） | **~55%** | 审核/机型/结算/看板/灰度在，缺**内容安全、风控、工单、对账、熔断、合规** |
| 合规与安全 | **~10%** | 三层 AI 备案、机器人安全国标、个保法、责任边界——**几乎全空** |

**四类"机器人专属刚需"自检结果**（这类是手机 App Store 没有、机器人平台必须有、也最容易被漏的）：

| # | 刚需 | v3.1 现状 | 结论 |
|---|---|---|---|
| 1 | 设备**全生命周期**（登记/绑定/解绑/转移/多设备/一机一码） | 有登记+绑定+`transferring` 字段，**无解绑/转移接口**、无一机一码列 | 🔴 半 |
| 2 | 技能**兼容性 / 回退 / 熔断** | 兼容性✅、回退✅（P1）、**无"熔断 kill switch"** | 🟠 缺 1/3 |
| 3 | 安全**责任与事故闭环** | 三层责任模型✅、**无事故上报/责任追溯/责任保险** | 🟠 缺下游 |
| 4 | **AI 三层备案** | **零** | 🔴 空 |

## 4. 结构性结论（要重审的三处）

**S1 · §9「砍独立 Vue3 双后台，全落 Bagisto Admin」必须重开。**
这条在 v3.0 的"省事"视角下成立，在"头部水平、开发者端全覆盖"目标下**不成立**。头部标配是独立开发者门户。**建议**：保留 Bagisto Admin 做**平台运营端**，**新增独立开发者门户**（可先做 Web 端，复用现有 API + internal.key 升级为开发者 OAuth/Key）。这条不改，开发者端永远是 20%。

**S2 · §1.2「净缺口总览」只列了 5 项，漏了整个开发者端和合规。**
缺口盘点口径要按"三端 + 合规安全"重列，否则排期会系统性低估。

**S3 · 排期 4 周 P0 装不下。**
当前 P0 已含支付+审核+下发+试用+沙盒，再叠加本报告 P0 项（开发者门户、内容安全、工单、通知、售后政策、熔断、备案、技能搜索、评价接入），**至少扩容到 8–10 周**，且**合规（备案/资质）是外部审批，必须像微信支付一样前置并行**。

## 6. 建议：v3.2 补全清单（按优先级）

**P0-补（不补就不算头部，且多数是冷启动/合规的硬前提）**
1. **独立开发者门户**（注册/入驻/协议签署/技能 CRUD/版本/提交/审核状态/驳回/申诉）
2. **开发者数据看板**（下载/安装成功率/机型分布/错误码/评分/卸载率）
3. **凭证与 Key 生命周期**（AppID/Secret） + **预发布测试轨**（真机 Beta 分发）
4. **内容安全检测**（技能名/描述/图标/预览视频）
5. **技能类目/属性/搜索**体系
6. **工单/客服**（用户↔平台↔开发者）+ **消息通知中心**（微信订阅消息）
7. **虚拟商品售后/退款政策** + 售后单
8. **技能熔断 kill switch** + 存量设备回滚
9. **合规**：隐私政策 + 个保法 + **AI 三层备案**（算法/大模型/拟人化互动）
10. **评价/优惠券接入技能 + 前端页**（复用 Bagisto 底座）
11. **设备解绑/转移** + 一机一码列

**P1-补**：对账、发票、开发者结算面板、支付/刷单风控、团队 RBAC、开发者文档/SDK/CLI、仿真与真机调试工作台、事故上报与责任保险、复审申诉、驳回理由库、审核 SLA。
